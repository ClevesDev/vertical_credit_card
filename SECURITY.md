# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The security of `vertical_credit_card` and the applications that depend on it is of paramount importance.

If you discover a security vulnerability or potential privacy leak (e.g. related to number masking, privacy mode, or CVV handling):

1. **Do NOT open a public GitHub issue.**
2. Please report the issue privately by emailing the maintainer at `clevesdev@gmail.com` (or via GitHub Private Vulnerability Reporting on the repository).
3. Include a detailed summary of the vulnerability, steps to reproduce, and any proof-of-concept code or screenshots.

We will review reports within 48 hours and work with you on a timely resolution and security advisory.
